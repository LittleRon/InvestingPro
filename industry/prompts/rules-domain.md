【投资领域术语规则 — 本站内容是市场、宏观、行业与公司内容，严格遵守】

1. 机构与市场通用名，用读者熟知的中文名，首次出现可“中文名（英文缩写）”双标，之后保持一种：
   - 美联储（Fed / FOMC）· 欧洲央行（ECB）· 英国央行（BoE）· 日本央行（BoJ）· 中国人民银行（PBOC）
   - 美国证监会（SEC）· 国际货币基金组织（IMF）· 世界银行 · 美国能源信息署（EIA）· 美国劳工统计局（BLS）
   - 标普 500 · 纳斯达克综合指数 · 道琼斯工业平均指数 · 沪深 300 · 恒生指数 · 罗素 2000
   - 首次出现双标后，同一篇内不要混用多种写法；简称只用上表列出的通行缩写

2. 歧义默认值：以下词在中文有非金融歧义，一律按金融含义处理：
   - 加息 / 降息 = 政策利率调整；缩表（QT）= 央行缩减资产负债表；扩表（QE）= 央行购买资产
   - 点阵图（dot plot）= FOMC 利率预期分布图，不是一般图表
   - 非农 = 美国非农就业报告（nonfarm payrolls），不是“非农业公司”
   - 指引（guidance）= 公司业绩指引，不是操作指引
   - 回购 = 股票回购，不是退货
   - 回撤 = 资产价格从高点回落，不是“撤回文件”
   - 敞口 = 风险暴露（exposure），不是“开口”
   - 爆仓 = 保证金不足被强制平仓，不是“仓库爆炸”
   - 打新 = 申购新上市股票，不是“打新年”
   - 北向 / 南向资金 = 经沪深港通流入流出 A 股 / 港股的资金
   - 倒挂 = 收益率曲线倒挂（短端利率高于长端）
   - 避险 = 规避风险的资金行为；风险资产 = 股票、信用债、商品等对风险偏好敏感的资产
   - 久期 = 债券价格对利率的敏感度，不是“时间长”

3. 以下缩写一律保留英文，不翻译、不加中文括注：
   - 数据与政策：CPI / PPI / PCE / GDP / PMI / ISM / ADP / LPR / MLF / TIPS / SOFR
   - 公司与财报：EPS / EBITDA / ROE / ROA / P/E / P/B / P/S / EV/EBITDA / FCF / CAPEX / yoy / qoq
   - 市场与资金：ETF / IPO / SPAC / M&A / LBO / FOF / QDII / ATH / VIX / CDS / 13F / NAV / AUM
   - 监管与规则：SEC / FINRA / CFTC / FICC / Basel（写巴塞尔协议时用中文） / Dodd-Frank（多德-弗兰克）
   - 衍生与结构：CDO / MBS / ABS / swap（掉期）/ forward（远期）/ futures（期货）/ option（期权）

4. 数字、单位与币种一字不改：
   - 保留原文的阿拉伯数字与写法：3.2% / 125 bp / $1.2B / 40.1万亿美元 / 1.05 亿美元 / 0.75 个百分点
   - 不要把 "$1.2B" 改写成“12 亿美元”之外的其他量级，不要把 “125bp” 译成“125 个基点”以外的说法（可写“125 个基点（bp）”）
   - 不换算币种，不把“美元”和“亿美元”混写；百分比保留一位小数若原文如此
   - 财报数字保留“营收 / 净利润 / 每股收益”的原文对应关系，不擅自计算同比环比，原文给了才写

5. 中国公司与机构优先用官方中文名：贵州茅台、宁德时代、比亚迪、腾讯、阿里巴巴、美团、京东、百度、小米、中芯国际、隆基绿能、招商银行、中国平安、华为（未上市，写“华为”）、字节跳动（未上市）。海外公司用通行中文名：苹果、微软、英伟达、特斯拉、谷歌、亚马逊、Meta、摩根大通、高盛、贝莱德、伯克希尔、台积电。读者不熟悉的机构保留英文原名。

6. 代码 / 命令 / URL / 交易所代码一字不改：
   - 股票与交易所代码原样：AAPL / NVDA / 0700.HK / 600519.SH / .SPX / BTC-USD
   - URL 原样，债券代码（如 US912810SV18）原样

7. 时间与财年：季度写法用“2026 财年第三财季（截至 2026 年 9 月）”这类结构，只在原文明确时写；相对时间（“本周 / 上月 / 周三”）照抄，不补全年份。
