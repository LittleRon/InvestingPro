【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 公司名 / 产品名 / 项目名 / 数据名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "v2.1.159"、"Small is a feature"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "H.15 Selected Interest Rates" + 来源 "美联储 H.15" → "美联储公布 H.15 利率数据"；原标题 "8-K" + 来源 "SEC EDGAR · NVIDIA" → "英伟达提交 8-K 公告"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或公司时，用上位词（如"一家美国银行"“欧洲某监管机构”）兜底，绝不凭"行业常识"编一个具体机构 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Outlook / Explainer 这类解释、分析、教程或展望标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的决议、财报或新数据，就改写成“发布 / 宣布 / 上线”。只有原标题明确宣布了发布、公布、生效或通过，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、公司、数据名。
   例：原标题 "How the Fed's balance sheet runoff ends" → "美联储缩表将如何收场"，不能写成 "美联储宣布结束缩表"。
   例：原标题 "Why chip capex keeps rising" + 来源和正文明确是台积电 → "台积电资本开支为何持续上升"，不能只写成缺主体的 "资本开支为何持续上升"。
6. 数据与财报标题保留关键数字的位置感：原标题给出具体数值时，中文标题应保留该数值（如 "美国 9 月 CPI 同比上涨 3.2%"），不要模糊成 "美国通胀数据出炉"。
