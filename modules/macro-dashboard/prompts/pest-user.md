按四个象限写：

政治：与财政、货币、监管、贸易、产业政策相关的当期变化。快照里的价格与周期数据本身不算政治，除非它能直接对应到政策动作。
经济：价格（CPI、PPI）、能源与大宗商品、指数基金与贵金属的水平与变化，以及三个周期各自处在什么位置。
社会：就业、收入、人口、消费结构这类有数据支撑的项。快照里没有就直接写"本日无数据"。
技术：全要素生产率、研发投入强度、专利申请量这些能反映技术一侧投入与产出的项。

每段两到四句，句子短，不写套话，不重复快照里没有的内容。最后另起一段，给最多四条"关注要点"。
